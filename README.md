# Animal Shelter Bot

## Описание проекта

Animal Shelter Bot — учебный проект SkyPro по разработке Telegram-бота для автоматизации работы приюта животных из Астаны.

Проект направлен на упрощение взаимодействия между приютом, потенциальными владельцами животных, усыновителями и волонтёрами.

## Цель проекта

Разработать приложение на Java и Spring Boot, которое позволит пользователям получать информацию о приюте, знакомиться с правилами усыновления животных и отправлять ежедневные отчёты после передачи питомца новому владельцу.

## Основной функционал

### 1. Взаимодействие с пользователем

- Приветствие пользователя.
- Главное меню Telegram-бота.
- Выбор интересующей информации.
- Возможность обратиться к волонтёру.

### 2. Информация о приюте

- Контактная информация.
- Адрес и режим работы.
- Правила посещения.
- Правила безопасного общения с животными.

### 3. Подготовка к усыновлению

- Правила знакомства с животными.
- Перечень необходимых документов.
- Рекомендации по перевозке животного.
- Подготовка дома к появлению питомца.
- Советы по уходу и адаптации животного.

### 4. Ежедневные отчёты

- Регистрация новых владельцев животных.
- Приём ежедневных отчётов с фотографиями и текстом.
- Хранение отчётов в базе данных.
- Напоминания о необходимости отправить отчёт.
- Уведомления для волонтёров.
- Контроль испытательного периода.
- Уведомление владельца о результатах испытательного периода.

### 5. Серверная часть

- Работа с PostgreSQL.
- REST API для обработки GET- и POST-запросов.
- Обработка исключений.
- Автоматизированное тестирование.

Функционал будет уточняться в соответствии с официальным техническим заданием.

## Технологии

- Java 17
- Spring Boot
- Maven
- Spring Web / REST API
- Spring Data JPA
- PostgreSQL
- Telegram Bot API
- JUnit 5
- Mockito
- Git и GitHub

Зависимости будут добавляться постепенно по мере разработки проекта.

## Этапы разработки

1. Создание Spring Boot проекта и настройка GitHub.
2. Анализ требований и проектирование архитектуры.
3. Создание и подключение Telegram-бота.
4. Реализация меню и справочной информации.
5. Реализация работы с владельцами и ежедневными отчётами.
6. Разработка уведомлений и функционала волонтёров.
7. Разработка REST API и подключение базы данных.
8. Тестирование, исправление ошибок и подготовка релиза.

## Организация разработки

Для работы с Git используются следующие ветки:

- `main` — стабильная версия приложения.
- `dev` — основная ветка разработки.
- `release` — подготовка релиза.
- `feature/*` — разработка отдельных задач.

Завершённые задачи объединяются с `dev` через Pull Request.

Планирование, сроки и статусы задач ведутся в Yonote.
