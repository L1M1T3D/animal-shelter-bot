                     # План разработки Animal Shelter Bot

## Этап 1. Подготовка проекта

**Результат:** создан репозиторий с работающим Spring Boot приложением.

Задачи:
- Создать Spring Boot проект.
- Создать репозиторий GitHub.
- Настроить ветки main, dev, release и feature.
- Добавить README.md.
- Подготовить пространство в Yonote.

## Этап 2. Проектирование

**Результат:** подготовлена архитектура приложения.

Задачи:
- Изучить техническое задание.
- Определить основные компоненты приложения.
- Спроектировать структуру базы данных.
- Определить модель взаимодействия с Telegram API.
- Подготовить структуру пакетов.

## Этап 3. Подключение Telegram

**Результат:** бот принимает команды и отправляет сообщения.

Задачи:
- Зарегистрировать бота через BotFather.
- Настроить конфигурацию и безопасное хранение токена.
- Реализовать обработку входящих сообщений.
- Реализовать команду /start.
- Подготовить главное меню.

## Этап 4. Информационные сценарии

**Результат:** пользователь может получать информацию о приюте и усыновлении.

Задачи:
- Реализовать справочную информацию о приюте.
- Добавить правила посещения.
- Подготовить инструкции по усыновлению.
- Реализовать рекомендации по уходу.
- Добавить возможность обращения к волонтёру.

## Этап 5. Владельцы и отчёты

**Результат:** владельцы могут отправлять ежедневные отчёты.

Задачи:
- Реализовать хранение данных владельцев.
- Реализовать отправку фотографий и текста.
- Реализовать сохранение отчётов.
- Проверять полноту предоставленных данных.
- Добавить управление испытательным периодом.

## Этап 6. Уведомления и волонтёры

**Результат:** автоматизирован контроль отчётности.

Задачи:
- Настроить напоминания владельцам.
- Реализовать уведомления волонтёрам.
- Добавить возможность обратной связи.
- Реализовать обработку результата испытательного периода.

## Этап 7. База данных и API

**Результат:** серверная часть работает с постоянным хранилищем данных.

Задачи:
- Подключить PostgreSQL.
- Создать сущности и репозитории.
- Реализовать сервисный слой.
- Разработать необходимые GET- и POST-эндпоинты.
- Реализовать обработку исключений.

## Этап 8. Тестирование и релиз

**Результат:** протестированная версия проекта.

Задачи:
- Написать модульные тесты.
- Написать интеграционные тесты.
- Проверить пользовательские сценарии.
- Исправить обнаруженные ошибки.
- Подготовить релизную версию.
- Обновить документацию.

## Правила работы с Git

1. Новая задача начинается в отдельной feature-ветке от dev.
2. Изменения фиксируются осмысленными коммитами.
3. Для объединения изменений создаётся Pull Request в dev.
4. Перед объединением выполняются тесты.
5. В release переносятся проверенные изменения.
6. main используется для стабильной версии.

## Организация задач

Задачи, сроки выполнения, приоритеты и результаты фиксируются в Yonote. По окончании этапа документация обновляется.
